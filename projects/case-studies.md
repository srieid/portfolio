# Case studies

Two long-running jobs, written up in plain terms. Client code and private details stay private.

## amberandgreen.com.sg

**Client:** an exhibition booth company in Singapore.
**My role:** server, website and maintenance, for the last four years.
**Site:** [amberandgreen.com.sg](https://amberandgreen.com.sg)

### What they needed

A website for the business and a server to run it on, set up and looked after by one person.

### What I did

- **Server.** I built and set up the VPS the site runs on.
- **Design and build.** I designed and developed the WordPress website in Divi. It has a video hero at the top, a portfolio of past booths that visitors can filter, and a WooCommerce shop.
- **Maintenance.** I've looked after the site and the server since then: updates, fixes and changes when the business needs them.

### Why it matters

The same person who built the server and the site keeps them running, so nobody has to learn the setup again when something needs fixing.

## droid-life.com

**Client:** Droid Life, a US technology news site.
**My role:** rescue, upgrade and migration.
**Site:** [droid-life.com](https://www.droid-life.com/)

### What they needed

The site had PHP errors and problems on its VPS. The job was to get it stable, bring it up to date, move it to a new theme and make it fast.

### What I did

1. **Fixed the PHP problems** that were causing errors on the site.
2. **Fixed the issues on the VPS**, so the server itself was dependable again.
3. **Brought the application up to date** to the latest versions.
4. **Migrated the site to a new theme**, keeping the existing content in place.
5. **Cleaned up** what was no longer needed after the move.
6. **Optimised the site for speed.**
